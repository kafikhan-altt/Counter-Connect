# CounterConnect (Localo) — Out-of-Scope Ideas & Future Phases

The following features and suggestions were cataloged as out of scope for Phase 0 (to preserve strict focus and high reliability):

1. **Online Payments (UPI, Cards, Wallets)**
   - Phase 0 uses "pay at counter on pickup".
   - Future: Razorpay/Cashfree/UPI deep linking.

2. **Customer Accounts & Profiles**
   - Phase 0 supports friction-free guest ordering (name + phone) with order UUID and "Find my order" lookup.
   - Future: OTP-based customer login, favorite counters, re-order history.

3. **Vendor Self-Registration & Onboarding**
   - Phase 0 sets up vendors and food courts via Django admin / management commands.
   - Future: Self-service vendor registration and automated contractless onboarding.

4. **Multi-Language Support (Hindi / Regional Languages)**
   - Especially beneficial for Tier-2/3 food courts (Bhilai, Bhopal, Raipur).

5. **Group Ordering**
   - Friends adding items to a single shared cart / session and splitting the bill.

6. **Order Scheduling**
   - Allowing pre-orders scheduled for a specific time slot later in the day.

7. **Automated WhatsApp / SMS Alerts**
   - Live push or WhatsApp notifications when individual counter parts or the full order become ready.

8. **Camera-based QR Code Scanning for Vendors**
   - Phase 0 uses 4-character pickup code entry (robust, fast, doesn't require camera permissions or special lighting).
   - Future: HTML5 camera QR scanner for instant one-tap collection.
